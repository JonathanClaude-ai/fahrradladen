# Radlwerk München

Website für einen fiktiven Fahrradladen in München (Verkauf, E-Bikes, Werkstatt).

## Stack
HTML, CSS, JavaScript (kein Build-Schritt)

## Struktur
- `index.html` – Startseite
- `impressum.html`, `datenschutz.html` – Rechtliches (Platzhalterdaten vor Livegang ersetzen!)
- `css/styles.css` – Mobile-first Styles, Design-Variablen in `:root`
- `js/main.js` – Navigation, Formular-Validierung, Karten-Einwilligung
- `images/` – komprimierte Bilder mit alt-Text

## Lokal starten
`index.html` im Browser öffnen.
